# 🐸 蛙居 · 小院

**🌐 在线试玩：[https://umlla.github.io/wawa/](https://umlla.github.io/wawa/)**

一个纯文字风格的放置挂机小游戏。小院会自己长出三叶草，小蛙会自己出门旅行、寄回明信片，也会在家看书、种地、发呆。没有输赢，只有慢慢等着它回来的那种感觉。

**单文件 HTML，无需服务器，打开即玩。**

---

## ✨ 特性

### 🍀 挂机产出
- 三叶草随时间自动增长，受**天气**、**心情**、**饱食度**、**姿态**、**永久装备**多重加成
- 六种设施可升级：苔藓地毯 → 后院小池 → 南瓜灯笼 → 三叶草田 → 风车小屋 → 许愿星
- 产出曲线经过调校，最便宜的行囊物品约需 **25 分钟** 攒出，节奏偏慢

### 🌦️ 天气系统
七种天气轮换，各自影响产出、旅行速度和稀有明信片概率：

| 天气 | 产出 | 特点 |
|------|------|------|
| ☀️ 晴 | ×1.25 | 心情涨得快 |
| ⛅ 多云 | ×1.00 | 平稳 |
| 🌧️ 雨 | ×1.50 | 产出最高，心情下降 |
| 🌬️ 风 | ×0.90 | 旅行最快 |
| 🌫️ 雾 | ×0.85 | 随机事件翻倍 |
| ❄️ 雪 | ×0.75 | 稀有明信片概率翻倍 |
| 🌙 星夜 | ×1.15 | 心情回复最快 |

### 🐸 居家姿态
小蛙在家时会自己切换动作，共 **14 种**：

- **通用**：打盹、看书、种地、泡茶、发呆、写信、吃点心
- **天气专属**：晒太阳、看云、屋檐听雨、听风铃、雾中踱步、接雪花、屋顶看星星

姿态会影响产出和心情。种地时产出 +30%，看星星时心情涨得最快，写信时还有极低概率自己画一张明信片夹进相册。

### 🎒 旅行与行囊
- 出门时长 **10 分钟到 2 小时**随机
- 出门期间**无法互动**（摸摸、投喂、食物按钮全部禁用）
- 可以提前在**行囊**（12 格）里准备物品，小蛙出门时会全部带走
- 物品会在旅途中被使用或送给朋友，**天气对应的衣物优先触发**
- 旅行事件不定期发生，频率不高于 5 分钟一条，平均约 25 分钟

### 📮 明信片相册
- 每次旅行带回 1～4 张明信片（受“行”装备加成）
- 三档稀有度：**普通 / 稀有 / 传说**，边框和光效不同
- 20 个地点，每个地点有多条随机文案

### 🏠 生活与消耗
- **饱食度**随时间下降，饿了会扣心情、降产出，需要定时投喂
- **自动喂食器**：持续消耗三叶草，自动维持饱食度（小蛙出门时暂停）
- **衣食住行**四类永久装备，每类三档，价格从几百到几万不等

### 💾 自动存档
- 使用浏览器 `localStorage`，每 10 秒自动保存
- 关闭页面后重新打开，会结算离线收益（最多 8 小时，效率 50%）

## 🎮 怎么玩

1. 打开 [在线试玩](https://umlla.github.io/wawa/)，小院开始自动产出三叶草
2. 前期先攒钱升级**苔藓地毯**，产出会慢慢变快
3. 注意顶栏的**饱食度**，掉了就投喂，别让它饿着
4. 有余力就去**生活**面板买行囊物品，准备让小蛙出门
5. 点 **出门旅行**，然后等它自己回来——可能会很快，也可能很久
6. 收明信片、升级设施、攒钱买装备，循环往复
